Configuración necesaria — Supabase
Para activar la sincronización en tiempo real, crea esta tabla en Supabase:

Ve a tu proyecto → SQL Editor → pega y ejecuta este código:

create table rugido_plan (id text primary key, data jsonb not null, updated_at timestamptz default now());

Luego ve a Authentication → Policies, selecciona la tabla rugido_plan y activa Enable RLS → Add policy → Allow all.
